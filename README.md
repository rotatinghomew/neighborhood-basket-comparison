# 邻里商圈价格篮子的缺货与替代

这里保存邻里商圈价格篮子的缺货与替代工作所用的匿名合成记录。文件不包含分析结果或居民个人资料。

## 资料

`samples/` 中每个文件都是独立的 UTF-8 JSON 文档：`quotes`、`shops`、`needs`、`discounts`、`households`、`corrections`、`publication`、`aid`、`claims`、`redemptions`。日期是当地日历日期。空值表示没有对应观测或状态资料，不是数值零。

price_cents 为报价单位的分值，grams 是单位克重，step 是一次购买的单位倍数。报价按同周同店同时段适用。折扣的 units 是最低整单购买单位数；maximum 是折扣可用次数。会员条件由家庭资料列明。

## 运行

使用 Python 3.11，无需第三方依赖或服务。

```bash
python3 inspect_samples.py                 # 盘点原始记录数
python3 -I -m unittest discover -s tests   # 全部业务规则测试（31 项）
python3 -I run_basket.py briefing          # 每周公开简报（JSON）
python3 -I run_basket.py plan --week 2026-08-31 --household 单次取货 --district 上街
python3 -I run_basket.py triage            # 更正后的编辑三类分诊
python3 -I run_basket.py corrections       # 更正前/后差分与券重核清单
```

建议用 `python3 -I` 运行，避免当前目录中的同名模块污染导入。

## 分析引擎（`basket/`）

| 模块 | 职责 |
| --- | --- |
| `data.py` | 资料装载、索引、按 `as_of` 日期应用更正（重放历史视图） |
| `planner.py` | 窗口/路程/会员/步数/携带约束下的整篮方案枚举与最优选择 |
| `compare.py` | 固定可比、区间比较、无法比较三级分类与固定篮子成本 |
| `aid.py` | 片区补贴上限、菜券试算、促销兑换池、核销台账 |
| `corrections.py` | 更正影响差分、未发券重核、编辑分诊 |
| `briefing.py` | 每周公开简报与站长片区视图 |
| `cli.py` | 命令行入口（经 `run_basket.py` 调用） |

### 核心口径

1. **缺值不补零**：`未采价` 是没有观测，`缺货` 是确凿无货，两者分开报告；只有 `有货` 且有价格的报价能成交。
2. **凑包是真实支出**：满足需求的手数 `n = ceil(需求克重 / (step × 单位克重))`，多出来的克重照算钱、照算携带重量，但不产生新的需求满足。
3. **替代按需求授权**：替代关系只取自 `needs` 登记；同一商品在一笔采购里至多填满一个需求（河街粳米同时是两个需求候选时，其中一个必然报缺项）。
4. **折扣按整单判定**：只有整单单位数达到 `units` 门槛才计优惠；为凑门槛额外购买的部分计入支出与重量，超重即淘汰；优惠反而多花钱时不采纳。
5. **三级可比性**：同片区、同固定商品、同换算克重且两周都有有效观测才算固定可比；尺度不一致或只有替代证据归入区间比较；两周都无固定品有效观测为无法比较。补贴口径只使用固定可比层。
6. **补贴上限**：固定完整篮子成本上升等额增加、下降等额减少，单周封顶 `max_weekly_change_cents`；不可比较时沿用旧上限并注明原因，绝不按替代最低价调整。
7. **菜券与促销池**：券款为 `min(可行采购成本, 片区上限)`，超出列居民自付；同一组促销兑换份数是共享约束，不能给两户各开一张够用的券；买不齐时列缺项与可行替代安排，不用未获准替代凑账面。
8. **券生命周期**：已送达未核销仍占预算；核销按店家实际履约转已用；取消或到期才释放；有效期内不调低已发券额度。
9. **更正可重放**：`as_of` 早于更正 `received` 即得到更正前视图；旧简报与已核销事实保留可查，尚未发出的券按更正影响清单重核。

## 测试

- `tests/test_samples.py`：原始记录间的引用关系（随仓库提供）。
- `tests/test_basket_engine.py`：基于样本手算数字的端到端规则断言。
- `tests/test_edge_cases.py`：基于 `tests/fixtures/edge_cases` 最小合成夹具的会员、窗口、凑单超重与折扣净收益边界。

夹具与样本资料完全隔离，仅用于边界规则，不参与业务简报。
